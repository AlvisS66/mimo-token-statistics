# 首轮明细前端分页

## Report

**What was built** — 首轮明细表的条数下拉从「只显示前 N 名」改为「每页条数」（10 / 20 / 50，「全部」仍一次画完）；表格下方新增翻页控件：`共 N 条 · 第 x / y 页`、上一页 / 下一页、antd 形态的页码按钮（当前页附近 5 个 + 首末页、缺口省略号、当前页高亮）与「跳至 [ ] 页」回车跳转。只渲染当前页的行；口径（时间范围 / 选中日期 / agent / 分桶 / 搜索词 / 页大小）变化回第 1 页，刷新与 15 秒自动刷新保留页码，行数变少时收到最后一页。纯前端：不改接口、不升版本串，发布说明并入 v1.0.3。

**Verification** — `python -m unittest discover -s tests -v` → 44 tests OK（2.0 s）；`python -m py_compile server.py` → OK；`node --check js/app.js` → OK。有头浏览器场景（Playwright，临时服务 `127.0.0.1:8798` 服务本 worktree，`range=all` 1,102–1,104 条首轮）：每页 10 条只渲染 10 行、控件「共 N 条 · 第 1 / 111 页」；第 2 页与第 1 页无重复行；末页 18/18、余 7 行（= 177 − 17×10）；「全部」全量且行序与改动前一致；跳 57 = 第 561–570 行并显示 `1 … 55 56 57 58 59 … 111`，跳 100 显示 `1 … 98 99 100 101 102 … 111`，跳 999 → 第 111 页、跳 0 → 第 1 页、`abc` 清空且不动；六类筛选变化均回第 1 页、刷新留在第 2 页；键盘 Tab + Enter 可翻页且焦点保持在当前页；0 console error、0 page error。独立评审（`general-3`）：PASS，无 critical，两条 nit 已在 `b0e1450` 修复并复验。

## [S1] Problem

主页六个列表里，「首轮明细」是唯一不在服务端截断的：`/api/first-round` 把窗口内的全部首轮一次返回，全历史目前 1,105 条（约 550 KB）。条数下拉选「全部」时一次画完所有行——2026-11-26 实测一次渲染约 130 ms（脚本 18 ms + 浏览器排版 117 ms），而且此后每 15 秒自动刷新、每次改筛选都会重画一遍。成本在浏览器排版，不在脚本，也不在服务端（冷算 ≤ 0.6 s，缓存命中 ≤ 11 ms）。数据继续增长会从「顿一下」变成明显卡顿。

下拉选 10 / 20 / 50 时虽然没有性能问题，但只能看到前 N 名，后面的行没有入口。

其余五个列表要么服务端已截断（会话 50 / 项目 30 / 归并 100），要么天然很小（模型、agent），不在本次范围。

## [S2] Design

仓库没有 JS 测试框架：T1、T2 的证据是有头浏览器的前后对照（改动前先跑出基线，改完后用同一个脚本复跑）。

### S2.1 条数下拉改为「每页条数」

`#firstround-limit` 的 10 / 20 / 50 从「只显示前 N 名」改为「每页 N 条」，默认仍是 10；「全部」（0）保持原义——不分页、一次画完，留给需要在页内查找的场景。`localStorage` 键（`mimo-ts-fr-limit`）不变。

### S2.2 翻页控件

表格下方（`.table-scroll` 之后）加一行：左边 `共 N 条 · 第 x / y 页`，右边「上一页」、页码按钮、「下一页」和「跳至 [ ] 页」，按钮复用 `.btn.ghost`（尺寸略小），页码按钮与跳页照 antd 的分页形态。只有一页时（「全部」模式、或行数不超过页大小）整行隐藏；首页禁用「上一页」，末页禁用「下一页」。页码按钮显示当前页附近 5 个加首末页，缺口用 `…` 表示，点击即跳，当前页高亮（`aria-current="page"`）；跳页在输入框按回车生效，越界收到第 1 / 最后一页，非数字清空且不跳。只渲染当前页的行；排序规则不变（分桶 → 命中率升序 → 消耗降序），搜索与分桶筛选仍先作用于全量数据再分页。

### S2.3 页码何时回到第 1 页、何时保留

渲染时对照「口径」：时间范围、选中日期、agent 筛选、分桶、搜索词、页大小，任一变化回到第 1 页；口径不变的重画（15 秒自动刷新、手动刷新）保留当前页。行数变少导致页码越界时收到最后一页。页码只存在内存里，不写入 `localStorage`。

### S2.4 发布说明

纯前端改动：不改接口，不升版本串。发布说明并入尚未推送的 v1.0.3（`RELEASE_NOTES_v1.0.3.md` 的「新增」补一条）。

## [S3] Out of Scope

- 服务端分页；以及让会话 / 项目 / 会话归并三张表的「全部」名副其实（服务端截断 50 / 30 / 100，已知问题）。
- URL 深链接到某一页、页码持久化。
- 搜索框逐字输入的渲染开销（输入有 160 ms 防抖，本次未量到）。
- 其余五个列表的分页。
